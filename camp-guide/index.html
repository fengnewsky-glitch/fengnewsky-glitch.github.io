00 / 先看全程

带好一场营，围绕两条学习线

孩子：从适合自己的起点，完成三天“看、听、读、思”英语阅读体验。
家长：每天学习家长课，理解英语学习的方法，知道怎样支持孩子。

主理人统筹带营的目标，是让家庭顺利开始、及时获得帮助、看清自己的收获，再由邀约代理承接适合的后续课程。即使暂时不报名，家长也应有实际收获。

01 / 主理人与协助人员

主理人先把全程带起来

主理人主要负责

  • 把本期排期、学习材料、分工和规则讲清楚。
  • 主持开营，发布每日任务，回答群内共性问题。
  • 安排案例和嘉宾，把握群里发布内容的节奏。
  • 查看本期学习与打卡情况，把问题交给对应代理或中心老师；如有副手协助整理，提前说明交接方式。
  • 主持结营，介绍后续学习，组织简短复盘。

副手可协助的事项（供主理人安排）

  • 整理学员名单，核对邀约代理和所属中心。
  • 协助会议、入口、材料、分享和结营准备。
  • 整理家长学习、孩子阅读和打卡记录。
  • 把未参与、不会操作、有困难的家庭交主理人确认。
  • 追看处理结果，配合奖牌核对，学习完整带营流程。

需要另外两类老师配合

邀约代理：持续跟进自己邀约的家庭，协助操作、了解需求、反馈处理结果，结营后沟通课程。客户进营后，代理继续参与服务。

中心负责老师／总代理：筹备学习中心或合营中心的负责老师，统筹本人及下级代理邀约学员的测评、定级和阅读难度问题。主理人负责把事情交到对应中心。

本期先明确谁接手：主理人先确认任务、记录、提醒、嘉宾配合和结营材料分别由谁处理。有副手时，再按实际情况约定协助内容。尚未交出的事项由主理人统筹，或协调对应老师接手，不默认副手已经承担。
02 / 营前准备

先把人、材料和学习起点接好

这一阶段的结果：每个家庭有人跟进、有阅读起点，知道如何参加。

主理人：先确定本期安排

  1. 确定时间与人员。明确开营、三天任务发布、嘉宾分享、每日反馈和第4天结营的安排，确认当期协助人员与各中心测评负责人。
  2. 准备学习材料。核对三节家长课在App内的名称与查找位置、孩子阅读安排、两份真实案例及一次嘉宾分享。
  3. 统一规则。明确本期费用说明、打卡方式、奖牌条件、课程价格与权益。未给出的具体规则先向团队确认。
  4. 确认交接位置。沿用一份本期共用表，说明各人更新什么、什么时候看反馈。

副手可协助：核对准备情况

  1. 收齐名单，逐户核对孩子年龄／年级、基础、邀约代理、所属中心和测评负责人。
  2. 检查家长是否进群，代理是否进营配合；把缺人、归属不清的情况交主理人处理。
  3. 核对测评和阅读起点是否已交回，系统与App操作说明是否可用。
  4. 把待帮助家庭、问题和负责人记在同一份表中，向主理人反馈。

测评怎样交接

有基础的孩子交所属中心负责老师安排测评，可采用一对一方式或提交指定朗读音视频；具体形式按当期确认。零基础孩子按统一安排启动阅读。中心老师交回阅读起点和注意事项，邀约代理协调家长，主理人核对是否有人还在等待，可安排副手协助整理结果。

逐户确认三件事

  1. 家长已在安卓平板或手机上下载App，能够找到当天家长课。
  2. 孩子的阅读起点明确，家庭能够找到阅读内容。
  3. 家长知道三天做什么、怎样反馈与打卡、遇到问题找谁。

请邀约代理确认这些准备。尚未准备好的家庭写明原因与下一步，请主理人协调支持；准备情况与报名人数分开看。

交接完成：名单有归属、测评有结果或后续安排、材料可找到、待帮助家庭有负责人。

示例话术 · 主理人在团队内部交代本期安排

本期由我担任主理人。名单核对、参与记录和群内配合由我先统筹，协助安排会在本期通知里说清楚。请各代理继续跟进自己的客户，各中心老师负责本体系学员的测评与阅读起点。 本期时间、学习入口和共用表位置统一见本期通知。有未准备好的家庭，请在表内写明问题与跟进人，及时告诉我。
03 / 开营仪式

腾讯会议里，把“怎么开始”演示清楚

这一阶段的结果：孩子愿意参与，家长能找到课程、阅读内容和打卡位置。

主理人：按这个顺序主持

  1. 介绍自己和伙伴。先与孩子熟悉，邀请孩子说名字、昵称或喜欢的事，给予具体回应。
  2. 介绍三天体验。用孩子听得懂的话说明将尝试什么，让他们对阅读有期待。
  3. 共享屏幕演示。进入阅读系统，展示从哪里开始、每天读什么、怎样提交反馈或打卡。
  4. 说明家长任务。展示App中三节家长课的查找方式，说明每天学习和反馈的安排。
  5. 收口到第一步。请家长确认能否找到入口，重申当天任务、求助方式及已确定的打卡规则。

副手可协助：会前、会中、会后配合

  1. 会前：检查会议通知、演示材料和共享屏幕，配合提醒代理通知家长。
  2. 会中：记录未到场家庭、操作问题和需要会后解释的事项，协助群内互动。
  3. 会后：把未到场及不会操作的家庭交给对应代理补充说明，在共用表跟进处理结果。
交接完成：会后群里有清楚的任务说明；未到场或不会操作的家庭已由对应代理接手。

示例话术 · 开营后的群内说明

接下来三天，家长每天完成当天家长课，孩子按适合自己的起点体验阅读。今天的课程位置、阅读安排和打卡方式见本条说明。 还找不到入口，请联系自己的邀约老师；阅读太难或太容易，也请及时告诉我们，由所属中心老师协助判断和调整。
04 / 第1天

帮助每个家庭顺利开始

今天重点看：开始了吗？卡在操作、阅读难度，还是时间安排？

早晨 · 发布当天任务

主理人做什么

把当天家长课的名称和App内位置、孩子阅读安排、反馈与打卡方式集中发清楚。提醒家庭按自己的阅读起点开始。

副手可协助（按当期安排）

提前检查材料和入口，发布后核对内容是否完整，收集“找不到、打不开、不会操作”的具体问题。

白天 · 发布第一份案例，回应问题

主理人选一份与本期孩子年龄或基础相近的真实案例，讲清初始情况、具体做法和真实变化。主理人收集家长回应，可请副手协助整理，区分共性问题和个别问题：共性问题由主理人集中说明，个别问题交代理或中心老师处理。

晚上 · 核对参与，接住未开始家庭

主理人确认当天记录已整理好，可请副手在共用表分别核对家长学习、孩子阅读和打卡情况；再看哪些家庭尚未开始或有困难，提醒对应代理了解原因。操作问题由代理先协助，级别与难度问题交所属中心负责老师。处理结果直接更新回同一份表。

今天做到这里：当天任务已发，第一份案例已分享；未开始家庭的原因有人在了解，已发现的问题有人负责。

示例话术 · 第1天群内任务开头

第1天，我们先把阅读开始起来。家长今天学习当天家长课，孩子按安排体验阅读。 家长学完后，可以分享一点新的理解。第一次操作遇到困难，请告诉自己的邀约老师；读起来不合适，也请及时反馈。
05 / 第2天

帮助家长理解方法，回应真实顾虑

今天重点看：家长理解了什么？实际体验中还担心什么？

早晨 · 继续学习，先回应前一天的问题

主理人做什么

发布当天家长课与孩子任务，回应前一天较集中的一个问题。对需要专业判断的事项，说明由哪位中心老师接手。

副手可协助（按当期安排）

先查看昨天未解决的问题，核对代理或中心老师是否更新了结果。把仍需主理人协调的事项单独提醒。

分享前后 · 配合一场嘉宾分享

主理人：按本期孩子的年龄与基础选择嘉宾，提前沟通分享提纲；分享时做简短介绍，结束后收集家长问题。

可请副手协助：核对分享时间、方式和材料，协助发布预告、提醒参加、整理问题和收尾信息。

给嘉宾的简短提纲

  1. 孩子开始时的基础和家庭困惑是什么？
  2. 具体怎样安排阅读和陪伴？
  3. 遇到什么困难，怎样调整？
  4. 后来有什么真实变化，还有什么正在继续努力？

保留实际经历及归属，帮助家长理解做法和过程。

晚上 · 汇总体验与顾虑

当天参与和问题由主理人确认接手人整理，可请副手协助；主理人提醒代理结合已有反馈了解家长的理解与顾虑。有明确问题再沟通，已有反馈直接记录，减少重复私聊。专业问题请所属中心老师处理后更新回表。

今天做到这里：课程与阅读继续，嘉宾分享完成；家长主要顾虑已记录，尚未解决的问题有跟进安排。

示例话术 · 邀请家长反馈

今天的学习和体验中，哪一点对您最有帮助？实际做起来，还有哪里没弄明白，或者让您有顾虑？欢迎告诉我们具体情况，我们一起看看需要什么支持。
06 / 第3天

收齐学习收获，为结营做好准备

今天重点看：家长获得什么、孩子怎样继续、家庭还需要什么支持。

早晨 · 发布最后一课和当天阅读

主理人做什么

发布第3节家长课及孩子任务，说明当天反馈的重点：一个收获、一个观察、一个还想解决的问题。

副手可协助（按当期安排）

核对三天记录中的缺项，分清“已完成”“未完成”和“待核实”。需要补充了解的，交对应代理确认。

白天 · 第二份案例与后续需求

主理人分享第二份真实案例，围绕持续阅读、家庭安排或困难调整。结合家长的反馈，请代理了解继续意愿和所需支持；愿意进一步了解课程的家庭，写清下一次沟通安排。

晚上 · 汇总三天，准备第4天结营

主理人：确认结营时间、总结顺序和当前有效的VAK课程说明，筛选可以用于结营的真实反馈。

可请副手协助：整理三天参与、家长收获、孩子阅读观察及符合奖牌条件的初步名单，把待核实的记录单独列清楚。

群里提前通知第4天结营。KET仅对有明确需求的家庭，由中心老师判断适配后个别介绍。

今天做到这里：三天记录基本齐全，家长收获与继续意愿已交回；结营材料和奖牌核对准备完成。

示例话术 · 收获征集与结营提醒

三天体验接近结束，欢迎用三句话回顾：我理解了什么；我观察到孩子什么；接下来还希望获得什么帮助。 明天我们会在群里结营，一起回顾这次体验，也会介绍后续学习方式。具体结营时间见本期通知。
07 / 第4天结营

群内图文总结，再分别承接每个家庭

这一阶段的结果：家庭看到真实收获，奖牌领取有依据，后续沟通有人承接。

主理人：按顺序完成结营

  1. 回顾本期做了什么。说明家长学习、孩子阅读及共同参与的过程。
  2. 分享真实收获。选择具体家长反馈和阅读观察，肯定孩子的尝试与坚持。
  3. 说明奖牌。依据本期已明确的规则，说明完成三天打卡可领取“阅读挑战王”奖牌，以及寄送安排。
  4. 集中介绍VAK。讲清孩子从哪里开始、每天怎样学、老师怎样支持，以及当前价格、期限和权益。
  5. 交给邀约代理承接。请有意了解的家庭联系自己的老师，代理结合三天记录分别沟通，写清下一步。

副手可协助：整理材料与交接

  1. 结营前把参与汇总、真实反馈、表彰及奖牌名单交主理人核对。
  2. 按主理人的发布节奏协助材料发送，整理结营中出现的问题。
  3. 核对符合条件家庭的收件信息，交指定寄送负责人处理；具体收集方式按团队安排。
  4. 汇总代理更新的课程沟通状态，提醒主理人哪些家庭还需要支持。
课程沟通从三天体验中接过来：群里统一主推VAK；有明确KET需求的，由所属中心老师判断后个别承接。价格与权益按当期确认资料介绍。
交接完成：结营已完成；奖牌名单、寄送负责人和后续家庭跟进人明确。尚未解决的事项有下一步。

示例话术 · 结营收尾

谢谢每个家庭参与这三天的体验。我们一起理解了阅读的方法，也观察到孩子开始和尝试的过程。 希望进一步了解VAK的家庭，请联系自己的邀约老师，我们会结合孩子的起点说明学习安排和服务。完成三天打卡的家庭，按本期已说明的安排领取奖牌。 暂时不报名，也欢迎把这三天学到的方法继续用起来。
08 / 每天都要做的交接

在一份记录里，把问题接到解决

  1. 主理人确认参与记录的接手人。可请副手协助整理；家长学习、孩子阅读、提交打卡分开记录；没有看到反馈的，先标“待核实”。
  2. 主理人查看异常。判断是统一答疑、代理联系，还是中心老师专业处理。
  3. 群内提醒接手。说清对应家庭、问题、负责人、反馈时间，并附共用表位置。
  4. 负责人更新结果。代理或中心老师直接在同一份表里写处理结果与下一步，减少重复抄报。
  5. 次日看未完成事项。由主理人确认接手人持续跟进；可请副手追看，直到解决或明确后续安排。

每天向两处反馈

家长群：简短总结、鼓励参与、提醒当天任务与求助方式。个别困难由对应老师私下了解。

团队代理群：同步本期参与汇总及需要谁接手的事项；明细和结果放在同一份共用表。

示例格式 · 内部提醒

今天的参与记录已更新到本期共用表。家长课、孩子阅读与打卡分别统计，待核实记录已标出。 需要接手：某家庭目前卡在某一步，请对应代理／中心老师在约定时间前处理，并在表里补上结果及下一步。主理人和当期协助人员查看同一份记录。
没有打卡，不直接等同于没有学习；说“已提醒”也不等于问题解决。交接看实际情况和处理结果。
09 / 营后收尾

把跟进、奖牌和复盘收好

主理人负责收口

  • 请代理更新已报名、愿进一步了解、暂缓及未联系上的家庭，各自有后续安排。
  • 确认奖牌寄送、费用记录与结算交接的负责人。
  • 组织一次简短复盘，确定下一期先改的一件事及负责人。

副手可协助整理

  • 汇总报名、参与、三天学习与打卡、课程意愿和实际付费记录。
  • 核对奖牌寄送状态及仍待处理的家庭，把遗留问题交清楚。
  • 总结学到的带营方法、独立完成的动作和下次需要支持的地方。

复盘只围绕四个问题

  1. 哪些家庭没有顺利开始，具体卡在哪里？
  2. 哪一步交接不清楚，造成谁在等谁？
  3. 家长最常问什么，哪种支持有帮助？
  4. 下一期先改哪一件事，谁负责完成？

有意愿与实际付费分开记录。统计课程转化时注明截至时间，口径统一为“本期实际付费正式课程家庭数 ÷ 本期实际报名家庭数”，退款情况另列。

收尾完成：待跟进家庭、寄送和费用都有明确交接，下一期有一项具体改进。
10 / 开营前统一的安排

主理人先拿到这些信息，再向团队和家长说明

以下信息整理在本期通知和共用资料中即可，本手册用于查阅步骤。

  • 排期与人员：开营、分享、每天任务和反馈、第4天结营的具体时间，主理人、当期协助人员、各中心测评负责人。
  • 学习入口：App准确名称、三节家长课的查找位置、孩子阅读内容和操作说明。
  • 打卡规则：家长、孩子分别需要提交什么，提交位置、截止时间、是否允许补交及补交安排。
  • 产品说明：VAK现行价格、期限、权益与服务支持；KET个别承接的负责老师。
  • 奖牌安排：完成三天打卡领取，具体核对口径、收件方式、寄送人和寄送时间。
  • 费用说明：39.9元体验价的本期收款、取消／退费及结算口径，向报名家庭说明。
仍需落实的细则：三节课的具体名称与位置、产品现行价格和权益、打卡对象与补交办法、寄送时间等，本轮尚未提供。按团队当期确认资料执行。

关于39.9元和带营报酬

此前研讨方向是取消完成打卡后的全额返现，将奖牌及邮寄开销之外的剩余费用给主理人，副手跟营学习暂不安排带营报酬。奖牌加邮寄当时估算约10—15元／人，实际按支出记录核对。正式收款说明、异常退款和结算办法仍需按本期确认口径执行。

“取消打卡返现”和其他情况下的退费处理分别说明；历史已报名家庭按其报名时的约定核对，遇到差异交主理人协调。

建议示例话术根据当期安排调整后使用。案例保留真实归属，以实际反馈说明收获；三天体验的观察不自动等同于长期能力提升。
