# 丸承三百载交互演示

用于确认透明屏展示系统的首页布局、四阶段关系与点击展开逻辑。

## 查看

线上地址：https://fengnewsky-glitch.github.io/wanji-demo/

本地直接打开 `index.html`，或通过任意静态网页服务器访问。本项目无构建步骤、无远程依赖、无数据提交。

## 已采用的交互

- 首页始终显示四个阶段入口，按 01 → 02 → 03 → 04 顺序围合排列。
- 点击一个阶段，显示阶段介绍和三个一级菜单。
- 点击一级菜单，显示对应二级图文。
- 点击其他菜单自动替换详情；点击其他阶段自动收起旧阶段及详情。
- 保留收起详情、收起本阶段；再次点击当前入口也可以收起。
- 按单点互动设计；电脑鼠标及手机触摸可用于演示。
- Escape 先收起详情，再收起阶段；支持浏览器全屏展示。

## 内容与边界

内容和参考图片来自用户提供的《丸剂的生产演变1.0（OLED）》。原始文档未随网页公开。

AI 示意图保留原图标记，产品及车间照片暂作演示参考。年份、技术和数据沿用现有内容稿，未作为已独立核验的历史结论。

网页背景用于电脑预览。“透明示意”显示透明区域的网格参照，不代表透明 OLED 实机的透光、亮度或遮挡效果。实际屏幕尺寸、分辨率和现场效果仍需设备联调。

## 文件

- `index.html`：网页结构。
- `styles.css`：桌面及移动显示样式。
- `app.js`：内容、图标、展开与切换逻辑。
- `assets/`：演示使用的文档配图。

四阶段、十二项主题、切换与收起、键盘 Escape、背景切换通过浏览器检查；检查了 1920×1080、1366×768、1024×768、768×1024、390×844 和 320×740 的内容溢出与入口遮挡；无脚本错误或素材请求失败。
